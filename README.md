# MoviePilot Plugins

自用 MoviePilot V3 插件集合。所有插件源码位于 `plugins.v3/<插件ID小写>/`，
索引为 `package.v3.json`。

## 安装

在 MoviePilot 的「设置 → 插件市场」中添加本仓库地址，或在插件市场搜索插件名安装。

也可以把本仓库路径加入 `PLUGIN_LOCAL_REPO_PATHS`，从本地仓库直接安装。

## 目录结构

```text
.
├── package.v3.json        # V3 插件索引
└── plugins.v3/            # 插件源码（目录名 = 插件类名小写）
```

## 说明

- 插件依赖由 MoviePilot 在安装时自动处理；如需离线依赖，可放在插件目录的 `wheels/`。
- 本仓库不包含任何私有凭据，服务地址与口令请在插件配置页填写。
