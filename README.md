# 🎬 MOVIEPILOT-PLUGINS

MoviePilot 第三方插件库（V3），收录自用插件，用于增强 MoviePilot 的下载、媒体库、音乐与运维能力。

> ⚠️ 注意：本插件库为个人维护，推荐优先使用官方插件库。

- **插件数量**：16 个
- **适配版本**：MoviePilot V3（索引文件为 `package.v3.json`）
- **插件目录**：`plugins.v3/<插件 ID 小写>/`
- **作者**：gldl137

v1.5.0 · Telegram,群组,下载,解压 · 机器人版自动解压：长轮询实时接收、转发即处理、支持代理

* 功能：把群里转发的压缩包交给 Telegram 机器人下载，立刻解压到「下载目录/completed」——所有文件平铺、不保留包内文件夹；同名文件可跳过/覆盖，解压成功后可删除原包。与本地目录监控版「压缩包自动解压（ArchiveUnpacker）」互为机器人版。转发的压缩包全部处理，无需关键词等过滤。
* 标签：Telegram,群组,下载,解压
* 作者：`gldl137`　仓库：[MoviePilot-Plugins](https://github.com/gldl137/MoviePilot-Plugins)
* 配置项（极简）：启用插件、Bot Token、Chat ID（可选白名单）、代理地址（http/socks5）、Bot API 地址、下载目录、压缩包后缀、同名文件（跳过/覆盖）、解压后删除压缩包
* 特点：
  * 🤖 只处理机器人私聊转发：把群里的压缩包转发给机器人即可，无需配置监控群组；无需开发者账号，只需 `@BotFather` 给的 Token。官方 API 单文件上限 20MB，可填自建 Bot API Server 地址解除，或把大包拆成小于 20MB 的分卷转发
  * ✅ 转发即处理：长轮询（getUpdates timeout=30）实时接收，无需公网 HTTPS 地址；只要是配置的压缩包后缀就下载解压，不再有关键词 / 大小 / 发送者 / 密码等过滤项
  * 🌐 代理：可手填 http / socks5 代理（访问 Telegram 与下载压缩包都走代理），留空则用 MoviePilot 系统代理
  * 📂 固定输出：解压文件全部平铺到「下载目录/completed」，不保留包内文件夹结构；同名文件可选「跳过已有 / 覆盖已有」（与本地版一致），默认跳过

## 📖 使用说明

1. 在 MoviePilot 「设置 → 插件市场」点击「添加仓库」，填入本仓库地址：
   `https://github.com/gldl137/MoviePilot-Plugins`
2. 保存后刷新插件市场，搜索插件名称安装（例如「喜马拉雅XM解密」）。
3. 安装完成后进入「设置 → 插件」，打开插件配置页填写参数并启用；部分插件支持定时任务或命令交互。

> 💡 本地调试：把本仓库路径加入 MoviePilot 的 `PLUGIN_LOCAL_REPO_PATHS`，即可直接从本地仓库安装，无需推送远程。
