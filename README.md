# 🎬 MOVIEPILOT-PLUGINS

MoviePilot 第三方插件库（V3），收录自用插件，用于增强 MoviePilot 的下载、媒体库、音乐与运维能力。

> ⚠️ 注意：本插件库为个人维护，推荐优先使用官方插件库。

- **插件数量**：13 个
- **适配版本**：MoviePilot V3（索引文件为 `package.v3.json`）
- **插件目录**：`plugins.v3/<插件 ID 小写>/`
- **作者**：gldl137

## 📖 使用说明

1. 在 MoviePilot 「设置 → 插件市场」点击「添加仓库」，填入本仓库地址：
   `https://github.com/gldl137/MoviePilot-Plugins`
2. 保存后刷新插件市场，搜索插件名称安装（例如「喜马拉雅XM解密」）。
3. 安装完成后进入「设置 → 插件」，打开插件配置页填写参数并启用；部分插件支持定时任务或命令交互。

> 💡 本地调试：把本仓库路径加入 MoviePilot 的 `PLUGIN_LOCAL_REPO_PATHS`，即可直接从本地仓库安装，无需推送远程。

## ⚠️ 注意事项

1. 本插件库中的插件均为个人维护，使用前请仔细阅读插件说明。
2. 本仓库适配 MoviePilot V3，索引文件为 `package.v3.json`。
3. 部分插件需要事先配置好下载器、媒体服务器或通知渠道才能正常工作。
4. 插件依赖由 MoviePilot 在安装时自动处理；如需离线依赖，可将 wheel 放入插件目录的 `wheels/`。
5. 本仓库不包含任何私有凭据，服务地址与口令请在插件配置页填写。
6. 如遇到问题，请先查看插件详情页日志或提交 Issue。
